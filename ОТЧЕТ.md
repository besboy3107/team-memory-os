# Отчёт: Team Memory OS

## Проблема
Команда хранит решения, инструкции и правила в разрозненных документах. Сотрудники тратят время на поиск, а ответы без источника трудно проверить.

## Решение
Team Memory OS объединяет документы и память решений, отвечает на вопросы по собственной базе, показывает источники и передаёт сомнительные запросы человеку.

## Сценарии
1. Новый менеджер спрашивает порядок онбординга.
2. Продажник уточняет обязательные поля квалифицированной заявки.
3. Руководитель проверяет, какие решения уже приняты командой.

## Контроль качества
Ответ содержит `answer`, `sources`, `confidence`, `needs_review`, `review_reason`. Если источника нет, вопрос короткий или содержит неопределённость, включается ручная проверка. Каждый запуск фиксируется в `audit_runs`.

## Мини-экономика
10 минут ручного поиска против 2 минут с системой. 100 вопросов дают экономию 800 минут / 13,3 часа.

## Развитие
PostgreSQL, загрузка PDF/DOCX, embeddings, роли доступа, версии документов, оценка качества ответов и подключение реальной LLM через сохранение текущего JSON-контракта.
